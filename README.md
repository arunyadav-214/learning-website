# Arun Learning Hub

A custom React and TypeScript About page for Arun Learning Hub. The project focuses on practical, project-based technology learning and uses honest project facts rather than placeholder student or course totals.

## Highlights

- Responsive About page
- Custom navy, blue, and amber visual theme
- Accessible semantic structure and keyboard focus states
- Reusable card components and Lucide icons
- Reduced-motion support

## Run locally

You need Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open the local address shown in the terminal.

## Build

```bash
npm run build
```

## Main files

- `app/page.tsx` — About page content and structure
- `app/globals.css` — colors, typography, and custom effects
- `app/layout.tsx` — title and page metadata
